# GPU Mining Simulator

Мобильный 2D-симулятор майнинг-фермы с видом сверху.

## Возможности
- Виртуальные BTC, ETH и GCOIN — только внутриигровые ресурсы.
- Покупка RX 6600, RTX 3060, RTX 4070 и RX 7900 XTX.
- Хешрейт, температура GPU, энергопотребление и расходы на электричество.
- Улучшения охлаждения, блока питания и ПО майнера.
- Продажа игровых BTC/ETH за GCOIN.
- Автосохранение и офлайн-прогресс через localStorage.
- Android WebView-оболочка и автоматическая сборка APK через GitHub Actions.

## Запуск в браузере
Открой `index.html` или включи GitHub Pages в Settings → Pages, выбрав ветку `main` и папку `/(root)`.

## Сборка APK
После добавления файлов GitHub Actions запускает workflow **Build Android APK**. Открой вкладку Actions, выбери успешный запуск и скачай артефакт `gpu-mining-simulator-apk`.

Сборка debug APK предназначена для тестирования. Для публикации в магазине потребуется отдельная release-сборка и подпись.

## Важно
Это симулятор: он не подключается к кошелькам, биржам или реальным GPU и не добывает настоящую криптовалюту. Все цены и доходы условные.
